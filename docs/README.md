## 📊 Stack Tecnológico

### Backend
- **Framework**: Flask 3.0.0
- **ORM**: SQLAlchemy 2.0+
- **Database**: SQLite (dev) / PostgreSQL (prod)
- **Autenticación**: JWT
- **Testing**: pytest

### Frontend
- **HTML5** + **CSS3** + **JavaScript ES6+**
- **PWA**: Service Workers + Manifest
- **i18n**: Sistema multiidioma (ES/EN)
- **Iconos**: Font Awesome 6.5
