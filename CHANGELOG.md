# Changelog

Todos los cambios notables de este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [Sin publicar]

### Agregado
- Sistema de gestión de finanzas personales completo

- Gestión de múltiples cuentas bancarias
- Sistema de transacciones con categorización automática
- Integración con IA (Groq) para análisis financiero
- Asistente de chat inteligente

- Validación de entradas

- Sanitización de datos
